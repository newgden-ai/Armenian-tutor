# Правила нормализации (сравнение ответов) — армянская версия

Правила реализованы одинаково в трёх местах и должны совпадать:
`scripts/build_vocab.py` (`key_uz`), база (`public.key_uz`, миграция learning_engine) и приложение
(`keyUz` в `app/src/normalize.js`). Имя `uz` — внутреннее, означает «изучаемый язык» (здесь армянский).

## Армянский текст для показа
- Unicode NFC, лишние пробелы схлопываются.
- ASCII-двоеточие `:` в конце предложения → армянская точка `։` (U+0589).

## Армянский ключ для сравнения
- Нижний регистр (заглавные Ա–Ֆ переводятся явно, не через локаль).
- `եւ` → `և` (обе записи принимаются).
- Удаляются знаки внутри слова: `՞` (вопрос), `՛` (ударение/восклицание), `՜`, `՚` и апострофы — `ինչպե՞ս` = `ինչպես`.
- Всё, кроме армянских строчных букв (ա–ֆ и և), пробела и дефиса → пробел; дефис → пробел; пробелы схлопываются.
- Личные местоимения в ответе необязательны: `ես գնում եմ` = `գնում եմ` (ես, դու, նա, մենք, դուք, նրանք).

## Русский ответ
- Нижний регистр, ё → е; пояснения в скобках удаляются; вся пунктуация → пробел.
- Варианты: вся строка целиком + каждая часть через `,` `;` `/`; числа можно писать цифрами.
- Армянское слово → принимаются варианты перевода всех слов с тем же армянским ключом.
- Русский перевод → принимаются армянские ключи всех слов с той же строкой перевода (без скобок).

## Полные дубли
- Одинаковые армянский ключ и русский перевод (со скобками) → одна карточка;
  основная — та, что раньше всех в порядке изучения (CEFR → тема → ID).
